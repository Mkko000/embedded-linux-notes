## ✨ Features
- **64 real terminal sessions** — actually executed, with every output line explained.
- **Interactive tools** — boot-sequence simulator, RM/EDF scheduling simulator, wildcard & regex playground, `chmod`/`umask` calculator.
- **Searchable command cheat-sheet**, glossary, and review questions.
- **Errata** — mistakes found in the original slides (curly quotes, `umask` math, `find -size k`, `vim dw` vs `de`, regex `.`), each verified and marked.
